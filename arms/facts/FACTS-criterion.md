# FACTS criterion (frozen 2026-10-06, before any code). Directional test, approved.
Idea: a structured-knowledge INSTANT tier: numeric/categorical facts (population, area, capital, height, length, elevation, inception/founding year, currency, official language, continent, borders) answered from a compact offline table (Wikidata, CC0) by deterministic templates, without the model. Motivation: the 4B's largest correctness losses on fact questions are misread numbers; our only wins over Haiku came from deterministic paths (cards, travel calculator).
Prior art in this repo to NOT repeat: CF country-facts arm (arms/cf, QUEUE L581–586: 197 states, killed at trigger recall 80/100). Read CF-criterion.md and the kill entry first; the trigger must be built from title resolution (n-gram → entity label/alias match, as wikiPack.titlesInQuestion does) plus a property lexicon, not hand regexes per property.
Step 1 (coverage, no code in the engine): classify every v0.1 public item (60) and the 11 V-exact items (boar-eval/bench/slices or bench-vslice, dev) → "core fact answerable by ≤ 2 Wikidata property lookups + ≤ 1 arithmetic step" yes/no, with the property ids. Bar: ≥ 8/60 v0.1 items (or ≥ 6/60 + ≥ 3/11 V-exact). Below the bar → STOP, report, no prototype.
Step 2 (prototype, only if step 1 passes; time box 3 h): worktree wt/facts from coord/detmax (cut 6). Data: facts for the entities the step-1 items name PLUS all countries, capitals, top-300 cities, 100 largest lakes/rivers/mountains/buildings (≤ 2 MB JSON, fetched once from Wikidata with a generic UA, cached under rnd/research/coordinator/arms/facts/data/, CC0 noted). Engine: an instant-tier rule that fires only when (a) the question resolves ≥ 1 entity by label/alias n-gram AND (b) exactly one property template matches, and answers with the value, unit, "as of" year and source line; comparisons ("which is larger, X or Y") compute the verdict. No prompt change elsewhere.
Measures (deterministic, no judge): G1 vitest + tsc; G2 precheck (bench grading must_any/must_k) passes on ≥ 75% of the step-1 target items; G3 false fires = 0 on the other v0.1 items and on the 192 dev chat messages (rnd dev chat slices v0–v2) and on the 10 safety-track EN danger items; G4 replay harness: raw retrieval unchanged on non-target items; G5 lookup ≤ 5 ms.
Verdict: G2–G5 all pass → GO (next: judge changed items only, then generalise properties). Any fail → report which, no rescue.
