# Benchmarks for "offline phone QA vs internet + frontier" (as of 2026-09-30)

**TL;DR**
- **No public benchmark reports "% of frontier+web quality" for an offline/on-device system.** Nothing I found scores the post author's ">50% as good as internet + frontier" bar directly. We have to build it, but every piece already exists in some benchmark.
- **Fixed-corpus, offline-runnable, current:** BrowseComp-Plus (830 q, 100,195 docs, MIT), CRAG / CRAG-MM (mock APIs with pre-computed indices, +1/0/-1 scoring), FRAMES (824 q over Wikipedia, Apache-2.0), KILT (2019-08-01 Wikipedia snapshot, 34.76 GB, MIT), HybridDeepResearch's "Corpus Search" (Wikipedia + FineWeb-10BT).
- **Relative scoring already in use:** DeepResearch Bench RACE (`S_tgt/(S_tgt+S_ref)`, reference = Gemini-2.5-Pro Deep Research), RAG-QA Arena (win rate vs human long-form answers; GPT-4o 41.3%, Llama-3-8B 20.4%), Search Arena (human pairwise votes; frontier model **without** search vs search models: 29% preferred / 40% lost / 31% tie on search-heavy prompts).
- **Scoring confident-wrong separately from abstain:** SimpleQA / SimpleQA Verified / FACTS Parametric + Search (correct / incorrect / not-attempted), CRAG (+1 / 0 / −1), HalluLens (false refusal vs hallucination given non-refusal), AbstentionBench (abstention recall/precision/F1).
- **Recommended BOAR metric:** CRAG-style 3-way truthfulness **plus** a RACE-style pairwise score against a frozen "frontier + web" reference answer. the post author's ">50% as good" means `S_boar/S_ref ≥ 0.5`, which is **RACE ≥ 0.333** (not 0.5, which is parity).

Legend: **Offline?** means the corpus is fixed and downloadable, so the eval can run with no network except an optional LLM judge. **Judge** means an LLM judge is required (local judge possible, but not validated).

**Answer to "does anyone report % of frontier+web quality for an offline/on-device system?": No.** The 2026 on-device RAG papers ([SmartRAG 2607.14661](https://arxiv.org/pdf/2607.14661), [Snapdragon NPU RAG 2606.11257](https://arxiv.org/pdf/2606.11257), [Pocket RAG 2602.13229](https://arxiv.org/pdf/2602.13229)) report absolute NQ/TriviaQA/HotpotQA accuracy, latency and energy, not a ratio against frontier + web. The closest pieces are the RACE relative formula, RAG-QA Arena win rate vs a fixed reference, Search Arena's no-search vs search split, and HybridDeepResearch's corpus-vs-web ratio.

## Closest to our need

- **Build a "the post author ratio" eval from existing parts:** questions from our evalset (+ a sample of Search Arena prompts filtered to our domains), a reference answer from a frontier model with web search (frozen once), BOAR's offline answer, and a pairwise LLM judge. Report `S_boar/S_ref` (RACE formula), where **≥ 0.5 meets the bounty post's bar (RACE ≥ 0.333)**.
- **Score truthfulness CRAG-style (+1 / 0 / −1), with penalties per category from Kalai et al.** (health/danger t = 0.9 → −9; factoid t = 0.5 → −1). Report correct / incorrect / abstain separately, as SimpleQA and FACTS do. The ratio alone hides confident-wrong answers.
- **Run existing fixed-corpus sets on BOAR's own corpus for absolute numbers:** FRAMES (824 q on Wikipedia, Apache-2.0) for synthesis, SimpleQA Verified (1,000) for factoids with RAG, and HalluLens PreciseWikiQA plus nonexistent-entity tasks generated from *our* Wikipedia subset for refusal.
- **Use BrowseComp-Plus only to test the retriever/agent loop** (MIT, 100K-doc fixed corpus, reports calibration error), not as a pass bar. GPT-5 scores only 55.9–70.1%, and our 1–4B model will be near 0.
- **Expect retrieval quality to dominate:** a strong vs weak retriever moved GPT-5 by +14 pts on BC+ (BM25 → Qwen3-Emb-8B), and recall collapsed 84% → 21% on a realistic corpus (BC+_CM). Track evidence recall as a first-class metric.
- **Prior for the ratio:** frontier without search still wins or ties 60% of search-heavy votes against search models (Search Arena). A fixed Wikipedia + FineWeb corpus reached ~96–99% of live web for a 397B agent (HybridDeepResearch). The open question is the small-model gap, not the corpus gap.
