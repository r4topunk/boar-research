## Card wording rule (2026-10-13)
Cards are published as the pack README (rnd/kiln/packs/publish_pack.py strips a few known internal paths and refuses anything that still looks internal: <users-dir>/, rnd/, arms/, wt/, coordinator, kiln, task ids like T-K3, host names such as mini/MacBook, e-mail addresses). Write cards from the start without those: say "build host Apple M4", "the pack converter", "the patched engine tree", and cite probes by date ("coverage probe 2026-10-13: …"), not by task id or file path. Internal references belong in the QUEUE and the arm reports, not in the cards.
