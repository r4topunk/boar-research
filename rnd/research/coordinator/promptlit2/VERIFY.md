## What holds up for our three models

- **Qwen3-4B-Instruct-2507 tools:** the 2507 Instruct hallucinates a tool on a no-tool query 3.4 % of the time, but misuses an irrelevant offered tool 24.0 % of the time (2510.22977 App. B). The risk is a distractor tool, not an invented one. Offer only relevant tools per turn and build a no-call test set with distractors (rows 3, 6).
- **Prompt lines will not fix tool over-calling:** "You must not use any tools that are not explicitly provided" moved hallucination from 90.2 to 87.5 (row 3). When2Call's 1.2 % needed RPO training (row 4). Expect the prompt to buy little and measure it.
- **Qwen3-1.7B thinking:** on TriviaQA the hybrid 1.7B gains +6.9 net with thinking but flips 5.38 % of correct answers to wrong. On 4B, SimpleQA barely moves (3.74 → 3.98 %) (row 2). Thinking is a possible small closed-book lever with a flip cost. It is not free, and it worsens tool hallucination (row 3).
- **Qwen sampling (both cards):** without thinking, use temp 0.7, top_p 0.8, top_k 20, min_p 0, and presence_penalty 0–2 only against repetition. `/no_think` is inert when `enable_thinking=False` (rows 8a, 8b).
- **llama.cpp b11010:** the `enable_thinking` kwarg still works but logs a deprecation warning. Move to `--reasoning off`, which also sets `enable_reasoning=0`, so re-check parser output after switching. #25067 and #20182 are not evidence that our path fails (rows 8c, 8d).
- **LFM2.5-8B-A1B config:** use temp 0.2, top_k 80, repeat penalty 1.05 and set no top_p. Tool calls are Pythonic inside `<|tool_call_start|>…<|tool_call_end|>`, which needs `--jinja` plus a build whose `common/chat.cpp` detects LFM2 (row 7d).
- **LFM2.5 reasoning budget:** there is no template switch to turn reasoning off; it skips reasoning only on trivial prompts. A max_tokens cap risks cutting the chain of thought, but Liquid's own vLLM example uses 8192. Size the cap so it is reasoning plus answer, and log which part truncates (rows 7b, 7c).
- **LFM2.5 role:** Liquid itself says the model is not for knowledge QA without retrieval. Its non-hallucination rate is high (63.47) and its accuracy is low (8.67). Use it only on the retrieval-grounded path, and expect abstentions rather than confabulation (row 7e).
