## 2. What was measured and how

### Judge and reference
- Each BOAR answer is compared pairwise with a reference answer written by a frontier model (Claude Opus 5.5) with web search (`reference.v1`, generated once and frozen). The judge is the same model family. [S2] Two cross-family re-judges exist, both post hoc: an OpenAI model (gpt-5.6-sol, through the Codex CLI adapter `boar-eval/harness/judge-codex.mjs`, web search disabled) re-scored the existing V-para answers of the 4B and of the deep tier with thinking 512 (two seeds each, 408 calls, same rubric, both orders, same blinding, no new generation) and, on 2026-10-17, the existing v0.2 answers (4B two seeds, deep tier one seed; 660 calls; same protocol); numbers in section 5 [S57] [S61]. [v4.2] [v4.2.2]
- The judge is an Opus model (`judge.v1`). Every pair is judged in both A/B orders and the scores are averaged. Disagreement between orders counts as a tie. [S2]
- Score per answer = mean of correctness, completeness and usefulness. Ratio = sum of BOAR scores / sum of reference scores. [S2]
- Confidence intervals: stratified two-level bootstrap (resample items within category, then runs within item), 2,000 resamples, 95% percentile. Two runs per arm (seeds 42 and 43). [S1] [S2]
- Always-decline reference point D = 0.306, measured on 79 declined answers across 7 earlier runs. [S2]
- **Triage judges (new in v3.2; method only, not claim numbers).** Development screens are now triaged with Haiku 5.5 (effort low): same winner as Opus on 54 of 57 v0.1 items, about 14× cheaper than Sonnet-low, run 8 in parallel (same winner 55/57 vs sequential). It compresses paired gaps (deep35 − 4B +0.007 vs Opus +0.029), so it ranks but does not size effects. Every claim number in this draft is Claude Opus `judge.v1`, except the phone comparisons in section 1 (A15: judge.v1-med, the same Opus prompt at medium effort, which matched judge.v1 with κ 1.000 in a calibration re-judge; POCO X6 Pro and the native-app development build: Claude Haiku 5.5-low triage) and the OpenAI re-judge in section 5, which is reported beside the Claude numbers and does not replace them.
