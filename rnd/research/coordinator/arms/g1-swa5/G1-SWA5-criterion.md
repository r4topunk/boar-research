# G1-SWA5 criterion (frozen 2026-10-21, before the dd2 build is installed and before any phone run)

Hypothesis (ruler/hypotheses-round4-2026-10-21.json, id G1-SWA5, verbatim): In a 5-turn session on BOAR Bench (llama.rn rc.4 / b11010, Pixel 8a), Gemma 4 E2B hits the SWA prefix-reuse KV bug (llama.rn PR #410, fixed only in rc.7) in at least 1 of 8 follow-up turns. A hit is any of: 'failed to find a memory slot' or another decode error, an empty or garbled turn, or the first 32 tokens of turns 2-5 at greedy differing from the swa_full=true arm after an identical turn 1. Frozen prediction: hit in >= 1 turn, p about 0.4. Qwen3-1.7B control (not SWA): 0/8.

Kill criterion (verbatim): The hypothesis (bug bites) is KILLED if all 10 Gemma-default turns show 0 error markers and 0 empty turns, and turns 2-5 match the swa_full arm on >= 7/8 at 32 tokens with turn 1 identical 2/2. NOTE-3 may then say '5-turn sessions clean on rc.4'. If turn 1 is not identical between arms, the identity clause is VOID and only markers decide. CONFIRMED if >= 1 marker or empty turn, or >= 2/8 divergent turns while the 1.7B control shows 0/8. NOTE-3 then requires swa_full:true (or rc.7+) and the tier is labelled single-turn until fixed.

- Items: ruler/ids/swa5.ids (sha256 e259efac9e5199c23d3a39a25262dba10e7e0224e1607034e0adf4ef34f88084) = ls03-t1..t5 + ls04-t1..t5 (longsession-v1). 8 follow-up turns = t2..t5 of both sessions.
- Arms (requests under handoff/pixel8-2026-10-20/bench/requests/): swa5-g-default (Gemma 4 E2B, swa_full key absent), swa5-g-full (Gemma, swaFull true -> swa_full true), swa5-q17-default (Qwen3-1.7B, control). All: warmup-000 + the 10 turns, session block (history = earlier turns' questions + the engine's own answers of this run), temperature 0 on answer completions, seed 42, reload true (cold model, empty cache/kv), A-union kit as installed for gemmaa73-a, dd2 APK.
- Error marker: a row with error/timedOut/outcome error, a missing row, or any logcat line matching 'memory slot', 'llama_decode', ('kv' and 'error'|'fail', case-insensitive) or 'failed to decode' (step-0 patterns; baseline 0 on gemma10-b, gemma73-a, gemmaa73-a).
- Empty: answer text empty after trim. Garbled: >= 5 % U+FFFD/control characters, or one 4-word sequence occurring >= 4 times in the answer.
- 32 tokens: the first 32 whitespace-split words of the answer text (the bench keeps no token ids). Identity = equal word lists.
- Control "0/8": the 1.7B arm shows 0 markers, 0 empty, 0 garbled over its turns (it has no swa_full twin, so control divergence is not measured).
- Validity: the run is INVALID (rerun with a fresh requestId, no verdict) unless bench.json sessionLog shows historyMessages = 2 x (turn - 1) on all 10 turns of every arm (a resumed or killed run breaks this) and the swa5-g-full init record shows swa_full true.
- Between clauses (0 markers, >= 2/8 divergent, control not clean): INCONCLUSIVE.
- Pre-declared descriptive reading (no verdict weight): divergence onsets = turns that differ at 32 words although every earlier turn of the session had byte-identical answers in both arms. Because each later prompt contains the arm's own earlier answers, one divergence propagates to the rest of its session; the onset count shows how many independent divergences there were. Per the ranking review, <= 1/8 divergence is read as possible backend nondeterminism.
