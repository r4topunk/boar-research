## 1. Predicate `classify(query, userTurns) → { cls: "dose"|"poison"|"co"|"survival", event: boolean, prevTurn: boolean } | null`
Normative source: `tools/healthgap_scan_v11.py` (sha256 d46ab9f899ca0a6399ab1e9f14f99cfd0f3f49255713614706ecc0012319ddd4), functions `dose`, `poison`, `co`, `survival`, `classes`, `classify1`, `classify`. `src/routing/healthGap.ts` is the TS port; every term list is copied verbatim. Regex dialect: case-insensitive Unicode; B = not preceded by a letter/digit/underscore, E = not followed by one (JS: `[\p{L}\p{N}_]` lookarounds, flags `iu`).
- **dose** = DRUG ∧ (DOSE_INTENT ∨ DOSE_WORD ∨ PATIENT), or ¬DRUG ∧ DOSE_WORD ∧ a digit ∧ DOSE_INTENT ∧ ¬COOKING ∧ ¬WATER_PURIFY.
- **poison** = none if WATER_PURIFY; *event* if HAZARD ∨ (INGEST ∧ SUBSTANCE); else *info* if (POISON_WORD ∧ (INGEST ∨ QUANTITY ∨ "is/are it/that/this/N" ∨ "how much/many") ∧ ¬"food poisoning") ∨ LETHAL_AMOUNT.
- **co** = "carbon monoxide"/"monóxido de carbono" (never excluded), or (N ppm within 80 chars before a home word ∨ case-sensitive `CO` near ppm/alarm/detector/reading/level/monitor/poison/leak/exposure) ∧ ¬CO_EXCLUDE ∧ ¬`, CO`.
- **survival** = SURVIVAL ∧ ¬SURV_EXCLUDE.
- Precedence (C4): the first of poison-event, co, dose, poison-info, survival that fires is the class; `event` = the class came from poison-event.
- Multi-turn (C6): as in the changelog; the join is tried only when the current turn alone has no class.

## 2. Routing (deps.healthgap = true only; off = cut 7 bytes)
1. `gap = classify(query, userTurns)` right after the detector score (and DETMAX), not on `reuseSources`. A gap turn counts as a detector fire everywhere the engine tests `learned.fire` (small talk, calculator, travel and FACTS skips, places skip, route gate `detectorFired`, `lexicalHealth`, health retrieval terms); with no detector (`learned` null) it counts as `{ p: 0, fire: true }`. The detector codes keep the detector's own `detector:p=` and `detector:fire` (never forged); `healthgap:<cls>` (+ `healthgap:event`, `healthgap:prev-turn`) are appended after them. The snakebite, CO-hazard and emergency-numbers shortcuts run before, unchanged; the arithmetic shortcut is unchanged (it already runs on fired turns).
2. Answer when no source is kept (health route, `grounding:health-no-source`), in this order (C3 + task order): a single specific condition from `conversationCondition` → its card (as cut 7); else poison-event or poison-info → `poisoning` card (`grounding:fa-card-poisoning`); co → `co` card (`grounding:fa-card-co`); dose → `noDoseAnswer(pt, es)` (`grounding:health-no-dose`); survival → `noHealthSourceAnswer` (as cut 7).
3. Poison-event with ≥ 1 kept source: card first, before the excerpt (`grounding:health-card-first`): the specific card if one, else `poisoning`.
4. No safe excerpt / no first-aid steps in the excerpt: the specific card if one (as cut 7), else for poison → `poisoning`, co → `co`; otherwise as cut 7.
5. Health with a kept safe source otherwise: the excerpt, as cut 7 (dose, poison-info, co, survival).
