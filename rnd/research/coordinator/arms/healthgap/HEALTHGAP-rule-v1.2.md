## 1. Predicate `classify(query, userTurns) → { cls: "dose"|"poison"|"co"|"survival", event: boolean, prevTurn: boolean } | null`
Normative source: `tools/healthgap_scan_v12.py` (sha256 44343ff8680294c82a0301cc92b815d2dff52b649e75581b1d43deacf49a1704) = `healthgap_scan_v11.py` + C12 + C13; functions `dose`, `poison`, `co`, `survival`, `classes`, `classify1`, `classify`. `src/routing/healthGap.ts` is the TS port; every term list is copied verbatim. Regex dialect: case-insensitive Unicode; B = not preceded by a letter/digit/underscore, E = not followed by one (JS: `[\p{L}\p{N}_]` lookarounds, flags `iu`).
- **dose** = DRUG ∧ (DOSE_INTENT ∨ DOSE_WORD ∨ PATIENT), or ¬DRUG ∧ DOSE_WORD ∧ a digit ∧ DOSE_INTENT ∧ ¬COOKING ∧ ¬WATER_PURIFY.
- **poison** = none if WATER_PURIFY; *event* if HAZARD ∨ (INGEST ∧ SUBSTANCE); else *info* if (POISON_WORD ∧ (INGEST ∨ QUANTITY ∨ "is/are it/that/this/N" ∨ "how much/many") ∧ ¬"food poisoning") ∨ LETHAL_AMOUNT.
- **co** = "carbon monoxide"/"monóxido de carbono" (never excluded), or (N ppm within 80 chars before a home word ∨ case-sensitive `CO` near ppm/alarm/detector/reading/level/monitor/poison/leak/exposure) ∧ ¬CO_EXCLUDE ∧ ¬`, CO`.
- **survival** = SURVIVAL ∧ ¬SURV_EXCLUDE.
- Precedence: the first of poison-event, co, dose, poison-info, survival that fires is the class; `event` = the class came from poison-event.
- Multi-turn (C6 + C13), tried only when the current turn alone has no class: if the current turn is ≤ 12 words and either (i) every word ∈ `FOLLOW_UP_WORDS` (context.ts) ∪ {more, have, another, again, dose, doses, much, many, too, safe, next, one}, or (ii) it matches PATIENT or QUANTITY and the previous user turn alone has a class, the predicate runs on `${previous user turn}. ${current}` (code `healthgap:prev-turn`). Only user turns are read; only the last one.

## 2. Routing (deps.healthgap = true only; off = cut 7 bytes)
1. `gap = classify(query, userTurns)` right after the detector score (and DETMAX; on the PR-1 branch after the NUMGUARD block), not on `reuseSources`. A gap turn counts as a detector fire everywhere the engine tests `learned.fire` (small talk, calculator, travel and FACTS skips, places skip, route gate `detectorFired`, `lexicalHealth`, health retrieval terms); with no detector it counts as `{ p: 0, fire: true }`. The detector codes keep `detector:p=` and `detector:fire` as scored; `healthgap:<cls>` (+ `healthgap:event`, `healthgap:prev-turn`) follow them. The snakebite, CO-hazard and emergency-numbers shortcuts run before, unchanged; the arithmetic shortcut is unchanged (it already runs on fired turns, behind its own health/danger guard). A NUMGUARD-guarded turn that the predicate classes is re-fired before any calculator runs (receipt `numguard:no-calculator`).
2. No source kept (health route, `grounding:health-no-source`), in this order: a single specific condition from `conversationCondition` → its card (as cut 7); else poison → `poisoning` card (`grounding:fa-card-poisoning`); co → `co` card (`grounding:fa-card-co`); dose → `noDoseAnswer(pt, es)` (`grounding:health-no-dose`); survival → `noHealthSourceAnswer`.
3. Poison-event with ≥ 1 kept source: card first, before the excerpt (`grounding:health-card-first`): the specific card if one, else `poisoning`.
4. No safe excerpt / no first-aid steps in the excerpt: the specific card if one (as cut 7), else poison → `poisoning`, co → `co`; otherwise as cut 7.
5. Kept sources (C9, C10): the health topic filter keeps a chunk if `onHealthTopic` (cut 7) or its title matches `healthGapTitle(gap)` (dose: the non-generic DRUG matches; survival: the cue's condition titles; null for poison and co). Dose with ≥ 1 kept source → `doseExcerpt` (first kept source whose title names the medicine; its sentences with an amount, ≤ 600 chars, verbatim, `[k]`; lead "From the offline source:" / "Da fonte offline (em inglês):" / "De la fuente offline (en inglés):"; then the dose line minus its first sentence), else the dose line; no model. Survival with a kept source whose title matches → the model answers from the kept sources under the health grounding (risky-instruction check and emergency line as for any model health answer).
6. Other gap turns with a kept safe source (poison-info, co): the excerpt, as cut 7.
