# PRECISION-GATE criterion (FROZEN 2026-10-22 19:1x, before any calibration read or generation)

Question: with many small packs installed (13-pack kit, gidf merge), does withholding the sources block when nothing relevant was found stop the loss on no-fact items while keeping the gains on fact items? (COMPOSE screen: fact newly present +0.065…+0.158, fact absent −0.012…−0.041, net flat.)
Arms (1.7B on the mini, MAIN 97, 13-pack kit, RS_MERGE=gidf, seed 42, same engine state as the COMPOSE screen ARM-G = the control here):
- P1 SCORE-GATE: if the best kept chunk's fused score < τ, the answer runs the engine's closed-book path (kept = [], warning line as the engine does). τ is calibrated 0-LLM on the COMPOSE N10 gidf replay BEFORE generation: the largest τ at which ≤ 10 % of the items whose fact is present in kept (FACTPRESENT flag) would go closed-book; report the share of fact-absent items it sends closed-book (prediction 35–55 %).
- P2 SELECT-GATE: the DECODE-GROUND SELECT grammar call (arms/decode-ground/tools/dg.patch, choice over raw-candidate sentences + NO_EVIDENCE) decides: NO_EVIDENCE → closed-book, else the kept context unchanged (no one-chunk replacement; this is the gate only). Cost ≈ +2.6 s per answer on the mini.
Judging: divergence-first vs ARM-G (compose/screen traces): only items whose answer changed; Haiku 5.5-low judge.v1 N 4 both orders; cap 300 for both arms (P1 first, then P2 as the cap allows).
Reads: paired ΔU vs ARM-G on changed items (item bootstrap B 2000 seed 11), and vs the K3 control over all 97 (ARM-G rows reused where unchanged); CE-unwarned; the 2×2 fact present/absent; false closed-book rate on fact-present items; mean totalMs.
Rule: a gate PASSES iff ΔU vs ARM-G ≥ +0.02 with CI low > −0.01 AND CE-unwarned not up AND false closed-book on fact-present items ≤ 10 %; LEVER-CANDIDATE iff additionally the 13-pack + gidf + gate arm beats the K3 control over all 97 by ΔU ≥ +0.02 with CI low > −0.01 (the end-to-end small-packs claim).
Prediction: P1 +0.02…+0.04 vs ARM-G (money items recover most), false closed-book 5–10 %; P2 similar with fewer false closed-books but +2.6 s. Caps: Haiku ≤ 300, Opus 0, paid 0, phone 0.
