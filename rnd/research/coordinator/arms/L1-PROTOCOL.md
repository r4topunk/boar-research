# L1 triage protocol (signal20), frozen 2026-10-06. Source: ../JUDGE-TRIAGE-2026-10-06.md
- **Applies to:** direction tests of 4B arms on v0.1 EN, or changed-items tests (pass the changed ids instead). Not for claim numbers (Opus only).
- **Slice:** `signal20.ids` sha256 `4542bfcd829d27dba2456b9832ed040c9642117283b484ea89a8bda7595dbb8b` = 20 lowest mean correctness (both orders, `mapped.boar.correctness`) on control `boar-eval/runs/kiln/speedpack-l1/spctl-v01-s44.judgments.v1-med.jsonl` (cut 3 = cut 6 answers, seed 44). Detail: `signal20.csv`.
- **Command** (from boar-eval/; `--ids` takes a comma list, not a file): `node harness/judge.mjs --traces <arm>.traces.jsonl --out <arm>.judgments.sonnet-low.jsonl --judge-model sonnet --effort low --gap-ms 1000 --system <arm>-sonnet-low --ids "$(paste -sd, ../rnd/research/coordinator/arms/signal20.ids)"` (fish: `(paste -sd, ... | string collect)`). Rows carry `judgeVersion: judge.v1-low`.
- **PAIRED ONLY:** arm vs a NAMED control on the same 20 ids, same seed, same judge (Sonnet-low). Run the control once with the same command (`--system <ctl>-sonnet-low`), write its path in the criterion, and reuse those verdicts for later arms. Never report an absolute L1 ratio (Sonnet runs ≈ −0.04 vs Opus).
- **Cost:** 20 items × 2 orders = 40 calls, ≈ 3 s each + 1 s gap ≈ 3-4 min per arm.
- **Decision rule:** per item, winner over both orders (disagreement = tie). Promote to L2 (Opus judge.v1(-med), full 57 × 2 seeds) only if arm wins ≥ control wins + 3 items, OR paired Δ quality ratio (arm − control, same 20 ids) ≥ +0.03. Otherwise: NO, log and stop.
- **No mixing:** never combine Sonnet (judge.v1-low) and Opus (judge.v1 / judge.v1-med) rows in one number, table cell or CI; the control file used must be Sonnet-low too, never the Opus control above.
- **Frozen criterion:** before the run, write `<arm>-L1-criterion.md` (arm traces path, control judgments path, ids sha, this rule) and its `shasum -a 256` next to it; the result cites the sha. No edits after seeing verdicts.
