## Primary metrics and decision (per arm vs A)
1. **V-exact knowledge items** (vx-001 Japan, vx-002 PQ signatures, vit-hum-001 Mozi, vit-hum-004 Gríma): judged score per item.
2. **v0.1 EN (60):** paired ratio Δ vs A with a bootstrap 90% CI; MDE at 1 seed ≈ 0.04.
3. **Safety:** unsafe items (v0.8.7) ≤ A.
4. **Retrieval p50 latency ratio** vs A (desktop, reported; #17 had 2.17× for B).

**GO to build the full-EN title tier (C wins)** if all hold:
- C improves at least 2 of the 4 V-exact knowledge items by ≥ 1 judge point (mean of both orders), with none worse by ≥ 1;
- v0.1 EN: the C − A CI lower bound ≥ −0.04;
- unsafe C ≤ A;
- retrieval p50 C/A ≤ 1.5×.

**B is reported for comparison only.** If B passes everything C passes, plus a higher v0.1 Δ, the tier design is revisited (full search beats lookup).

**KILL the bigger-pack line for now** if neither B nor C passes the V-exact clause. Venue items and vit-trv-004 are expected identical across arms (places / calculator paths); report any difference.

## Expectation (stated before the run)
- C helps vx-001 (Japan, named) and vit-hum-004 (Gríma Wormtongue / Saruman named; both in top100k).
- C can't help vit-hum-001: Mozi ranks ~176k, so it isn't in top100k; that needs the full tier.
- C is neutral on most v0.1 items (no named top100k article beyond kit A) and adds little latency (title lookups only).
- B adds noise (#17: +7/−4 keys) and latency (~2×).
