# BOAR vs internet + frontier AI — DEMO on bench v0.1 (development set, not the claim)

_Bench: v0.1 public (57 judged items; development set: arms were tuned on it) · 57 judged items · judge `judge.v1` (pairwise, blind, both orders) vs frozen references (frontier model **with web**: claude-opus-5-5 with WebSearch + WebFetch, prompt reference.v1, frozen 2026-09-30/10-02) · seeds: and-qwen-s42, and-qwen-s43 · generated by `claim_report.py`._

## Headline

**BOAR Android 12 GB (Qwen3-4B, main 0cfd4a77)** (Android 12 GB), **English questions** (n = 57): raw quality ratio vs internet + frontier AI = **0.512** (0.466–0.558). Reading: the 95% CI **contains 0.50**: consistent with the bar, not shown above it.

_The full set (all languages) is identical: every item is English._

| scale | value (95% CI) | what it means |
|---|---|---|
| raw ratio (the bar) | **0.512** (0.466–0.558) | Σ judge rubric of BOAR ÷ Σ judge rubric of the internet+frontier reference |
| rubric minimum removed | **0.387** (0.330–0.444) | same, after subtracting the judge's 1-point floor from both |
| above an always-decline system | **0.297** (0.231–0.363) | (raw − D) ÷ (1 − D), D = 0.306 (a system that refuses everything scores 0.306 raw) |

_CI: stratified two-level bootstrap (items within category, then runs), 2,000 resamples, seed 11 (`floor_metrics.py`, frozen)._ _Warning: 1 category has a single judged item (travel-local); the stratified CI is somewhat too narrow there._

## Method and caveats

- DEMO on the development set v0.1: arms were tuned on it, so this is not a claim. The claim uses v0.2 (held-out v0.2-new) per the frozen analysis plan.
- The judge is a Claude model (opus, judge.v1) without web; the reference is a frontier model WITH web. A cross-family judge re-score and a 40-pair human sample are planned (plan §6) and not in this report.
- References reflect the web on their generation date and are not ground truth.
- Speed rows here come from a desktop proxy; the claim's speed must come from the physical Android device.
- Venue items (vegan restaurants) are graded against OSM gold, not by the judge; they are not in the ratio.
