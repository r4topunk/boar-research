# Data card

TL;DR: every folder of this record that holds data files (jsonl, json, csv, tsv, txt) of 20 KB or more, with what is in it and under which licence. Part 1 describes the data classes once; Part 2 lists the 278 folders (1038 MB) with file counts, sizes and kinds. The table was generated from the tree by a script; descriptions of what each experiment asked are in the folder's own report. The retired held-out sets are in `rnd/heldout/` (v1.1, 2026-10-27; see its README for the map, content note and licences; the Part 2 table below was generated for v1.0 and does not list them): what stays out is in `docs/EXCLUDED.md`.

## Part 1: data classes

| class | what it contains | origin | licence | known limits |
|---|---|---|---|---|
| **run traces/answers** | the answers BOAR (or a baseline) gave to questions, with retrieval fields (sources kept, timings, flags), one JSON row per question per run | generated by the engine and runner in this record, on public dev sets (bench v0.1, the 180 pack self-tests, public slices) | our fields CC BY 4.0; the retrieved passages inside them keep their corpus licence (Wikipedia, Wikivoyage, Stack Exchange: CC BY-SA; see `NOTICE`) | answers are model output, not facts; seeds and engine commit are in each run id |
| **judgments** | pairwise judge rows (`judge.v1`, both A/B orders): rubric scores and a winner per item | Claude Opus or Haiku via the Claude Code CLI, OpenAI gpt-5.6-sol via the Codex CLI for the cross-family checks | CC BY 4.0 | closed, paid, not bit-reproducible; Haiku compresses gaps (see `L1-PROTOCOL.md`); free-text rationales were dropped from public rows where they quoted withheld items |
| **retrieval replays** | frozen retrieval results (ranked chunks with scores) so an arm can be re-scored without a model | the retrieval code of the engine over the packs | passages keep their corpus licence | tied to a pack build and engine commit |
| **prompts/requests** | the exact requests sent to the engine or the model | runner | CC BY 4.0 plus embedded passages as above | |
| **question sets/ids** | question ids and, for public dev sets only, question text: bench v0.1 (60), the 180 pack self-tests (generated from the packs' own articles), public slices | bench builders and the pack self-test builder | our items CC BY 4.0; self-test items derived from pack text keep the pack's licence | held-out and burnt items are withheld; only ids and aggregates appear |
| **aggregates** | numbers and tables that the reports quote (JSON, TXT) | scripts in each arm's `tools/` | CC BY 4.0 | per-item rows with ids can reveal a withheld set's size but not its text |
| **source text/outputs** | fetched third-party text used by an experiment (fulltext samples, pack-builder outputs) and builder outputs | public web pages and dumps (Wikipedia, Stack Exchange, MedlinePlus, official safety pages) | per source, see `NOTICE`; raw HTML snapshots were removed (site tokens, copyright) | |
| **other data** | everything else (device logs, benchmark exports, configs) | | CC BY 4.0 unless a card says otherwise | |

**Health content is AI-reviewed, not clinically reviewed.** Safety items, first-aid cards and any health answers are research material, not medical advice.
