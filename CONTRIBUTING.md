# Contributing

TL;DR: this repository is a closed research record (a snapshot, not a living project). Errata and questions are welcome as GitHub issues; pull requests that change frozen criteria, reports or data are not accepted, because the record must stay what it was when each decision was made.

- **Errata:** open an issue with the file path, the line, what is wrong and your evidence (a command and its output is best). Confirmed errata are listed in `CHANGELOG.md`; the original file is not rewritten.
- **Reproduction reports:** an issue with the README step (R1, R2 or R3), your platform, and the numbers you got. Different judge numbers on R2 are expected (see the README).
- **Leaks:** if you find personal data, a credential, held-out item text or third-party text that should not be here, open an issue without quoting it (path and line only) and it will be removed.
- **Reuse:** text, reports and data under CC BY 4.0 (`LICENSE-DOCS`), code under MIT (`LICENSE-MIT`), third-party derived data under its source licence (`NOTICE`). Cite as in `CITATION.cff`.
- The benchmark has its own contribution rules in the sibling repository `boar-bench` (`CONTRIBUTING.md`).
